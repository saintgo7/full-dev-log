# Change Log

All notable changes to the "devlog-hub" extension will be documented in this file.

## [0.1.0] - 2026-01-12

### Added
- Initial release
- WebSocket connection to DevLog Hub server
- File change tracking with debouncing and batching
- Sidebar panel with connection status and recent activity
- Status bar item with connection toggle
- Commands: connect, disconnect, syncNow, viewInsights
- Configuration options for server URL, auto-connect, sync interval
- Session start/end event tracking
