## 🎯 프로젝트 개요

### 목적
개발자의 모든 개발 활동(Git 커밋, 파일 변경, 터미널 명령 등)을 자동으로 수집하고 중앙에서 관리하는 플랫폼 개발

### 주요 기능
1. **자동 로그 수집**: Git, 파일, 터미널 이벤트 자동 캡처
2. **전문 검색**: 키워드 기반 개발 활동 검색
3. **타임라인 대시보드**: 시간순 활동 시각화
4. **프로젝트 그룹화**: 프로젝트별 활동 분류
5. **리포트 생성**: 일간/주간/월간 활동 리포트
6. **수동 메모**: 개발 관련 메모 작성 기능
